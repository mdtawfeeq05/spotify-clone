Spotify Clone UI Project 🎵
A pixel-perfect, static replica of the Spotify web player interface, built purely with HTML5 and CSS3. This project is an excellent exercise for anyone looking to sharpen their front-end design skills, focusing on layout, styling, and responsiveness without the complexity of JavaScript.

🌟 Features
This project is a visual clone and does not include backend functionality. The focus is entirely on the user interface.

Main Interface: A detailed layout of the main player, including the sidebar, main content area, and footer.

Sidebar Navigation: Styled links for Home, Search, and Your Library, along with playlist links.

Album & Playlist Views: Beautifully crafted cards for albums, artists, and playlists using CSS Grid and Flexbox.

Player Controls: A static but visually accurate music player bar with icons for play, pause, skip, and volume.

Responsive Design: The layout is designed to adapt gracefully to different screen sizes, from desktop to mobile.

🛠️ Technologies Used
The beauty of this project lies in its simplicity. We're getting back to the basics and mastering the core building blocks of the web.

HTML5: For structuring the content and creating a semantic layout.

CSS3: For all styling, including:

Flexbox: For aligning items and creating flexible layouts.

CSS Grid: For complex, two-dimensional layouts like the main content area.

Custom Properties (Variables): To maintain a consistent color scheme and make styling easier to manage.

Media Queries: To ensure the design is fully responsive.
